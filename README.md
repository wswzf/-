# 晾衣绳截图

一个 Windows 截图小工具：按快捷键截图，截好的图会像晾衣服一样**挂在屏幕顶部的一根绳子上**，要用的时候直接从绳子上拖下来，拖进微信、QQ、文档、浏览器都行。

## 下载

不想装 Python 的话，直接去右边的 **[Releases](../../releases)** 下载 `晾衣绳截图_v1.0.zip`，解压后双击 `晾衣绳截图.exe` 就能用。

> 首次运行如果 Windows 提示「已保护你的电脑」，点「更多信息」→「仍要运行」。没有购买代码签名证书的个人小工具都会这样。

## 怎么用

| 操作 | 效果 |
|---|---|
| `Ctrl + Alt + X` | 截图：拖动选区，单击截整屏，Esc 或右键取消 |
| 单击绳上的截图 | 复制到剪贴板 |
| 把截图拖出去 | 直接拖进聊天框、文档、文件夹 |
| 双击 | 打开原图 |
| 右键 | 复制 / 打开所在文件夹 / 另存为 / 删除 |
| 滚轮 | 截图多了左右翻看 |

右下角托盘图标右键可以：打开截图文件夹、把绳上的截图全部归档、改快捷键、设置绳上最多挂几张、开机自启、退出。

截图保存在 `图片\晾衣绳截图` 文件夹里。

## 从源码运行

需要 Windows 10/11 和 Python 3.10 以上：

```bash
pip install -r requirements.txt
pythonw clothesline.pyw
```

## 自己打包成 exe

```bash
pip install pyinstaller
python build.py
```

打包好的程序在 `dist\晾衣绳截图.exe`。
